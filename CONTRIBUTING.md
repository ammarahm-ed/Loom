# Contributing to Loom

Loom is maintained out of tree: a package of hash-tracked overrides applied to the unmodified
`react-native` from npm. The repository layout, the override workflow (`loom add`, `loom
upgrade`, `overlay` / `import-fork` against a react-native checkout) and the CLI are documented in
[Maintaining Loom](website/architecture/maintaining.md), with the model itself in
[Overrides model](website/architecture/overrides.md).
